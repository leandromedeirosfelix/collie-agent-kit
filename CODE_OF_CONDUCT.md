# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: we want participation in this project to be a harassment-free experience for everyone. Be respectful and constructive, welcome different viewpoints and experience levels, accept feedback gracefully, and focus on what is best for the community. Harassment, insults, personal or political attacks, and publishing other people's private information are not acceptable.

The Code of Conduct applies in all project spaces, such as issues, pull requests and discussions, and when someone represents the project in public.

## Reporting

Report unacceptable behaviour to [contact@colliesr.com](mailto:contact@colliesr.com). Every report will be reviewed and investigated promptly and fairly, and the reporter's privacy will be respected.

## Enforcement

The maintainers enforce this Code of Conduct following the [Contributor Covenant enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines): correction, warning, temporary ban or permanent ban, depending on the impact of the behaviour.
